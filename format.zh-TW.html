InkLayer 檔案格式

第 1 版 · 2026 年 11 月 4 日

InkLayer 的筆記庫就是一個普通資料夾：筆記是 Markdown 檔，畫布是 JSON Canvas 檔，PDF 保持原樣不動；手寫和圖層用一般 JSON 存在旁邊。任何 App 都能打開這些檔案，不需要 InkLayer 也讀得到。本頁說明第 1 版（"schemaVersion": 1）。

筆記庫資料夾

我的筆記庫/
  Notes/
    Physics.md                 筆記
    Physics.ink/               它的手寫，放在旁邊
    Lecture board.canvas       畫布（JSON Canvas）
  PDFs/
    Attention.pdf              不會被修改
    Attention.pdf.ink/         它的標註
  Attachments/
    images/  audio/  videos/  exports/
  .inklayer/
    manifest.json              筆記庫的 ID 和名稱
    folders.json               筆記庫裡顯示的資料夾
    favorites.json  signatures.json  tool_presets.json
    devices/                   每台裝置一個檔案
    sync.nosync/  cache.nosync/   只屬於這台裝置，可以放心刪除

路徑都相對於筆記庫，以 / 分隔。名稱以 .nosync 結尾的資料夾存放單一裝置的快取與同步狀態：不會被同步，刪掉也不會遺失任何內容（InkLayer 會重建）。

筆記

Markdown（CommonMark，加上 GitHub 的表格與待辦清單），和 Obsidian 的寫法相同：[[維基連結]]與 [[筆記|顯示文字]]、以 ![](Attachments/images/…) 插入的圖片、$…$ 與 $$…$$ 之間的 LaTeX，以及 InkLayer 會畫成圖形的 ```graph 區塊（其他 App 會顯示成程式碼）。

畫布與心智圖

.canvas 檔是 JSON Canvas 1.0，也就是 Obsidian Canvas 用的格式。InkLayer 額外的資訊放在卡片的 "inklayer" 物件裡（紙張樣式、紙膠帶），心智圖的卡片和連線則標上 "inklayerMindMap": true；其他 App 會略過這些欄位。畫布上的手寫存在 <名稱>.canvas.ink/。

PDF

PDF 檔本身永遠不會被修改。寫在上面的一切都存在它旁邊的資料夾 <名稱>.pdf.ink/：

  • document.json：文件的 ID 與頁面。
  • pages/page_0001.layers.json：該頁的圖層。
  • pages/page_0001.inklog.bin：該頁的手寫（見下方）。
  • text_boxes.json、outline.json（自己編的目錄）、review.json（標記要複習的頁面）、page_list.json（頁面順序）、recordings.json。
  • pdf_text.json：供搜尋用的 PDF 文字，掃描頁是在裝置上辨識的。只是索引，刪掉也沒關係。

圖層

每頁由下而上列出圖層，每層有 ID、類型（pdf_background、template、markdown、ink、shape、image、video 或 ai_overlay）、名稱、zIndex、visible、locked 和 opacity。

手寫

手寫是只會往後新增的紀錄：一行一個 JSON 物件，寫入後不再改寫。每一行新增或移除一筆筆跡：

{"schemaVersion":1,"op":"add_stroke","opId":"op_…","deviceId":"…","clock":10291,
 "createdAt":"2026-11-04T12:00:00.000Z",
 "stroke":{"strokeId":"stroke_…","layerId":"layer_…","pageIndex":0,"tool":"pen",
  "brush":{"color":"#111111","width":3.5,"opacity":1,"blendMode":"normal","kind":"fountain"},
  "points":[{"x":129.3,"y":391.2,"t":0,"pressure":0.41,"tiltX":0.1,"tiltY":0.2}]}}
{"schemaVersion":1,"op":"tombstone_stroke","opId":"op_…","deviceId":"…","clock":10292,
 "createdAt":"…","layerId":"layer_…","strokeId":"stroke_…"}
  • 點的座標以頁面單位計，不是螢幕像素。t 是從這一筆開始算起的毫秒；pressure 介於 0 到 1；tiltX、tiltY 依 W3C Pointer Events 的慣例，單位是弧度；roll 是筆身的旋轉角（Apple Pencil Pro），單位是弧度。筆沒有回報的欄位就不會出現。
  • 工具：pen、highlighter、line、rectangle、ellipse、arrow、polygon。筆的種類（kind）：ballpoint、fountain、brush_pen、pencil、marker、calligraphy、highlighter。
  • 編輯不會改寫既有的行：移動或縮放筆跡，是移除舊筆跡、再加入新的。兩台裝置的紀錄合併時，每個操作依 opId 只保留一次；移除會勝過它所移除的筆跡。

相容性

每個儲存的物件都帶有 schemaVersion。第 1 版之內可能新增選用欄位，讀取時會略過不認得的欄位。也可能出現新的值（例如新的筆種），舊版 InkLayer 可能打不開用到它們的檔案；新增時會列在這一頁。
