# inklayer.app

The InkLayer website, served by GitHub Pages at https://inklayer.app.

| Path | Page |
| --- | --- |
| `/` | Home (`index.html`, `index.zh-TW.html`) |
| `/privacy/` | Privacy Policy (`privacy/index.html`, alias `privacy.html`; `privacy.zh-TW.html`) |
| `/support/` | Support (`support/index.html`, alias `support.html`; `support.zh-TW.html`) |

Plain static HTML, readable without JavaScript. The pages mirror the copies in
the InkLayer app repository (`store_assets/public_web/`); change them there and
here together.
