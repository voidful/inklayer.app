InkLayer file format

Version 1 · 4 November 2026

An InkLayer library is an ordinary folder. Notes are Markdown files, canvases are JSON Canvas files, and PDFs stay exactly as they were. Handwriting and layers are kept beside them in plain JSON. Any app can open these files, and nothing needs InkLayer to read. This page describes version 1 ("schemaVersion": 1).

The library folder

My Library/
  Notes/
    Physics.md                 a note
    Physics.ink/               its handwriting, beside it
    Lecture board.canvas       a canvas (JSON Canvas)
  PDFs/
    Attention.pdf              never modified
    Attention.pdf.ink/         its annotations
  Attachments/
    images/  audio/  videos/  exports/
  .inklayer/
    manifest.json              the library's id and name
    folders.json               the folders shown in the library
    favorites.json  signatures.json  tool_presets.json
    devices/                   one file per device
    sync.nosync/  cache.nosync/   this device only; safe to delete

Paths are relative to the library and use /. Folders ending in .nosync hold one device's caches and sync state: they are never synced, and deleting them loses nothing (InkLayer rebuilds them).

Notes

Markdown (CommonMark with GitHub tables and task lists), as Obsidian writes it: [[wikilinks]] and [[Note|label]] (a link to a PDF page is [[file.pdf#page=4|label]]), images as ![](Attachments/images/…), LaTeX between $…$ and $$…$$, and fenced ```graph blocks that InkLayer draws as graphs (other apps show them as code).

Canvases and mind maps

A .canvas file is JSON Canvas 1.0, the format Obsidian Canvas uses. InkLayer's additions sit in an "inklayer" object on a card (paper patterns, tape, "link": true for a file shown as a link) or in "inklayerMindMap": true on a mind map's cards and lines; other apps ignore them. Handwriting on a canvas is in <name>.canvas.ink/.

PDFs

A PDF file is never changed. Everything written on it lives in the folder beside it, <name>.pdf.ink/:

  • document.json: the document's id and pages.
  • pages/page_0001.layers.json: the page's layers.
  • pages/page_0001.inklog.bin: the page's handwriting (below).
  • text_boxes.json, outline.json (your own contents), review.json (pages marked for review, and when each comes up again), page_list.json (page order), recordings.json.
  • pdf_text.json: the PDF's text for search, scanned pages read on the device. An index only: deleting it is safe.

Layers

Each page lists its layers bottom to top, each with an id, a type (pdf_background, template, markdown, ink, shape, image, video or ai_overlay), a name, zIndex, visible, locked and opacity.

Handwriting

Handwriting is an append-only log: one JSON object per line, never rewritten. Each line adds a stroke or removes one:

{"schemaVersion":1,"op":"add_stroke","opId":"op_…","deviceId":"…","clock":10291,
 "createdAt":"2026-11-04T12:00:00.000Z",
 "stroke":{"strokeId":"stroke_…","layerId":"layer_…","pageIndex":0,"tool":"pen",
  "brush":{"color":"#111111","width":3.5,"opacity":1,"blendMode":"normal","kind":"fountain"},
  "points":[{"x":129.3,"y":391.2,"t":0,"pressure":0.41,"tiltX":0.1,"tiltY":0.2}]}}
{"schemaVersion":1,"op":"tombstone_stroke","opId":"op_…","deviceId":"…","clock":10292,
 "createdAt":"…","layerId":"layer_…","strokeId":"stroke_…"}
  • Points are in page units, not screen pixels. t is milliseconds from the stroke's start; pressure is 0 to 1; tiltX and tiltY follow the W3C Pointer Events convention in radians; roll is a pen's barrel roll in radians (Apple Pencil Pro). Each is left out when the pen doesn't report it.
  • Tools: pen, highlighter, line, rectangle, ellipse, arrow, polygon. Pen types (kind): ballpoint, fountain, brush_pen, pencil, marker, calligraphy, highlighter.
  • Editing never changes a line: moving or resizing ink removes the old strokes and adds new ones. Two devices' logs merge by keeping every operation once (by opId); a removal wins over the stroke it removes.

Compatibility

Every saved object carries schemaVersion. New optional fields may appear within version 1, and readers ignore fields they don't know. New values can appear too (a new pen type, say), which older versions of InkLayer may not open; this page lists them as they arrive.
